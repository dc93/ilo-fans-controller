Base URL

http://your-server/index.php

All API endpoints are accessed via query parameters: ?api=endpoint_name

GET Endpoints

GET /index.php?api=fans

Get current fan speeds for all fans

Response Example:

{
  "Fan 1": 45,
  "Fan 2": 50,
  "Fan 3": 48,
  "Fan 4": 52,
  "Fan 5": 47,
  "Fan 6": 51
}
GET /index.php?api=temperatures

Get all temperature sensors with current readings and thresholds

Response Example:

{
  "CPU": {
    "current": 52,
    "upper_threshold": 85,
    "lower_threshold": null,
    "status": "OK"
  },
  "Ambient": {
    "current": 28,
    "upper_threshold": 42,
    "lower_threshold": null,
    "status": "OK"
  }
}
GET /index.php?api=health

Get system health status with warnings and errors

Response Example:

{
  "status": "healthy",
  "ilo_connection": "ok",
  "last_update": "2025-11-10T15:30:00+00:00",
  "fans": {
    "total": 6,
    "responding": 6,
    "errors": 0
  },
  "temperatures": {
    "count": 12,
    "max": 58
  },
  "warnings": [],
  "errors": []
}
GET /index.php?api=metrics

Get Prometheus-compatible metrics (text/plain format)

Response Example:

# HELP ilo_fan_speed_percent Fan speed in percentage
# TYPE ilo_fan_speed_percent gauge
ilo_fan_speed_percent{fan="fan_1"} 45
ilo_fan_speed_percent{fan="fan_2"} 50

# HELP ilo_temperature_celsius Temperature in Celsius
# TYPE ilo_temperature_celsius gauge
ilo_temperature_celsius{sensor="cpu"} 52
GET /index.php?api=history&range=24h

Get historical fan speed data

Parameters: range = 1h | 6h | 24h | 7d

GET /index.php?api=export

Export complete configuration as JSON file (download)

POST Endpoints

POST /index.php

Set fan speeds (individual or all fans)

Request Body (All fans to same speed):

{
  "action": "fans",
  "fans": 50
}

Request Body (Individual fans):

{
  "action": "fans",
  "fans": {
    "Fan 1": 40,
    "Fan 2": 50,
    "Fan 3": 60
  }
}

cURL Examples

            

                

                    
Get fan speeds:

                    
curl http://your-server/index.php?api=fans

                

                

                    
Set all fans to 50%:

                    
curl -X POST http://your-server/index.php \
  -H "Content-Type: application/json" \
  -d '{"action": "fans", "fans": 50}'

                

                

                    
Get Prometheus metrics:

                    
curl http://your-server/index.php?api=metrics
